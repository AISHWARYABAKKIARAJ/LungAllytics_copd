# 🫁 LungAllytics

## Multimodal AI for Precision COPD Staging

LungAllytics is a research-oriented multimodal deep learning framework designed for COPD GOLD staging using radiological imaging and clinical parameters.


## 🚀 Key Features

- Multimodal deep learning architecture
- Explainable AI using Grad-CAM
- Clinical and image fusion
- Sustainable AI using PCA optimization
- Research-oriented healthcare decision support

---

## 🧠 Models Used

- Clinical Model → XGBoost
- Image Model → ResNet50
- Ensemble Model → Late Fusion

---

## ⚙️ Core Technologies

- Python
- PyTorch
- TensorFlow
- XGBoost
- Scikit-learn
- OpenCV
- Flask

---

## 🔬 Methodology

- Chest X-ray feature extraction using ResNet50
- Clinical intelligence modeling using XGBoost
- Dimensionality reduction using PCA
- Multimodal late fusion ensemble learning
- Explainable AI visualization using Grad-CAM
